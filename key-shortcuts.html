Reference

Keyboard Shortcuts

Shortcut Action
Editing
F2 Edit node text
Shift + Enter Insert line break
Tab or Insert Create child node
Return / Enter Create sibling node
Delete or Backspace Delete node
Navigation
Up Go to up node
Down Go to down node
Left Go to left node
Right Go to right node
Clipboard & History
Ctrl + Z or Cmd + Z Undo
Ctrl + Y or Cmd + Shift + Z Redo
Ctrl + C or Cmd + C Copy branch
Ctrl + X or Cmd + X Cut branch
Ctrl + V or Cmd + V Paste branch
Map Actions
Ctrl + K or Cmd + K Add URL
Ctrl + O or Cmd + O Open mind map
Ctrl + A or Cmd + A Save mind map
Ctrl + P or Cmd + P Print mind map
Help
F1 Open help

Tip: On macOS, use Cmd where shortcuts show Ctrl/Cmd.
